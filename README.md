# Lethbridge Digital Marketing Website

A clean, modern single-page website focused on **Effective Digital Marketing for local businesses in Lethbridge, Alberta**.

Inspired by the structure and conversion-focused style of the [Groupon Merchant](https://www.groupon.com/merchant) landing page.

## Features

- Hero section with clear value proposition and stats
- Simple 3-step process
- Service cards (Local SEO, Google Ads, Social, Websites, Analytics, Reputation)
- Old way vs. new approach comparison
- Local Lethbridge focus section (Westside, Downtown, surrounding towns)
- Testimonials / social proof
- FAQ section
- Strong final CTA
- Fully responsive, modern teal design

## Live Preview

Open `index.html` in any browser, or enable GitHub Pages on this repo.

## Stack

- Pure HTML + CSS (no frameworks required)
- Inter font from Google Fonts
- Mobile-first responsive layout

## Customization

- Update the email in the final CTA (`mailto:`)
- Replace placeholder testimonials with real ones
- Add your own logo and brand colors in the CSS variables at the top of `index.html`

Built for local businesses across Lethbridge and southern Alberta.
